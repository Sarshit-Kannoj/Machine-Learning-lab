# Machine Learning Lab Assignment

## 1. Weather Program
This Python program accepts temperature and humidity as input and displays weather information.

**Input:**
- Temperature in Celsius
- Humidity percentage

**Output:**
- Temperature
- Humidity
- Weather condition (Hot, Cold, or Moderate)

## 2. Spam/Ham Filtering Model
This project uses the Multinomial Naive Bayes algorithm to classify text messages as Spam or Ham.

**Libraries Used:**
- scikit-learn

**Input:** A text message.

**Output:** Spam or Ham.
